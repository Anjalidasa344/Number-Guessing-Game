# 🎯 Python Number Guessing Game

A simple and interactive command-line game developed using Python. The computer randomly selects a number between 1 and 200, and the player must guess the correct number within six attempts.

## ✨ Features

- Random number generation between 1 and 200.
- Maximum of 6 guessing attempts.
- Helpful hints when the guess is too high or too low.
- Personalized welcome message using the player's name.
- Input validation for invalid entries.
- Option to play multiple rounds.
- Simple and beginner-friendly command-line interface.

## 🛠️ Technologies Used

- **Programming Language:** Python 3
- **Random Module:** Generates random numbers.
- **Built-in Input Handling:** Accepts player guesses and choices.
